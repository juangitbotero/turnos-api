# Architecture Decision Records (ADR)

This folder contains all architectural decisions made for the Turnos App.

## What is an ADR?

An ADR is a short document that records **why** an important technical or product decision was made. It is written once and never deleted — even if the decision is later reversed (we add a new ADR that supersedes it).

## Format

Each ADR follows this structure:
- **Status** — Proposed / Accepted / Superseded
- **Context** — Why did we need to make a decision?
- **Decision** — What did we decide?
- **Consequences** — What are the trade-offs?
